# 10. Branding / theming

Each tenant has a theme with design tokens (colours, radii, fonts, logo, favicon, login background), an optional custom domain, and per-project overrides. Tokens map to CSS variables used by Tailwind and the UI kit and to the ECharts and MapLibre themes. Later: custom navigation, labels/terminology overrides (for example renaming "Entity" to "Asset"), email templates, and white-label mobile builds.
