Dataset editor: tabs on the left

Today the left panel only lists tables, and Metrics and Parameters sit in the tabs under the results (Results · Columns · Metrics · Parameters). Moving them left keeps the bottom for what the query returns, and puts the things you define about the dataset next to the source it is made from. Three ways to do it.

A · Tabs on top of the panel (recommended)Sources, Metrics and Parameters as three tabs above the left panel, with counts. One thing at a time, familiar, and the same tab style as the rest of the app. The bottom keeps only Results and Columns.

B · Vertical tabsA slim strip (44px) where each entry is an icon with its name running vertically beneath it, read bottom to top: Tables, Metrics, Parameters, with a count badge. It takes the least width of any option and still shows names, like the side tabs in many code editors. The panel sits beside it, like a code editor. It scales to more panels later (history, notes) and, with titles, nothing needs a tooltip.

C · Sections you openThe left panel becomes a stack: Tables, Parameters, Metrics, each opening in place. You can see a parameter and the table it filters at once, and nothing is hidden behind a tab. The cost: the panel is busy once two or three are open.
